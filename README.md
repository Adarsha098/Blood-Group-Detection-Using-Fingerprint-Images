# Blood Group Detection Using Fingerprint Images

## Project Overview

This project explores the use of Deep Learning and Convolutional Neural Networks (CNN) for experimental classification of fingerprint-like images into different blood group categories.

The project was developed using Python, TensorFlow/Keras, NumPy, Matplotlib, and Scikit-learn in Google Colab.

## Blood Group Classes

The model contains eight classes:

- A Positive
- A Negative
- B Positive
- B Negative
- AB Positive
- AB Negative
- O Positive
- O Negative

## Technologies Used

- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Convolutional Neural Network (CNN)

## Project Workflow

Fingerprint-like images
→ Image preprocessing
→ CNN model
→ Feature extraction
→ Classification
→ Evaluation
→ Prediction

## Model

The project uses a CNN consisting of:

- Convolutional layers
- Max pooling
- Global average pooling
- Dense layers
- Dropout
- Softmax classification

## Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Running the Project

The project can be opened and executed using Google Colab.

Open:

`blood_group_detection.ipynb`

Then run the notebook cells sequentially.

## Important Note

This repository contains an experimental machine-learning proof of concept using synthetic fingerprint-like data. The results do not establish a medically validated relationship between fingerprint patterns and blood groups and should not be used for medical diagnosis.
